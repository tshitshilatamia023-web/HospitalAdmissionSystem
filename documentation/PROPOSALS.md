# The Cozy Book Café - Website Proposals

## Current Website Analysis

The current Part 1 website is a five-page static HTML website consisting of Home, About Us, Books & Café, Enquiry and Contact pages. The pages already contain relevant content, images, navigation links, forms and semantic HTML elements.

### Current strengths
- The website has five connected pages.
- Semantic HTML elements such as `<header>`, `<nav>`, `<main>`, `<section>` and `<footer>` are used.
- Images have alternative text.
- The Products page contains a structured book table and café menu.
- The Enquiry page contains a form with required fields.
- Navigation links are available across the website.
- README, sitemap, wireframe and changelog documentation are included.

### Current weaknesses and planned improvements
- The Part 1 website is mainly unstyled HTML and needs a consistent visual design.
- The pages need improved spacing, typography, colours and visual hierarchy.
- Navigation needs clearer hover/focus states.
- The Products table and Enquiry form need professional styling.
- The layout must work well on smaller screens.
- The website needs an external CSS stylesheet for Part 2.
- The design should remain consistent with the selected cosy café concept.

# Proposal 1: Cozy Book Café - Classic & Comfortable

## 1. Website Concept
The website will promote The Cozy Book Café as a warm and welcoming place where customers can enjoy books, coffee and light meals. The design will have a simple, comfortable and inviting appearance.

## 2. Goals and Objectives
- Introduce customers to The Cozy Book Café and its services.
- Display the books and café menu clearly.
- Provide information about the café, its mission and vision.
- Allow customers to send enquiries.
- Make contact and location information easy to find.
- Create a simple, accessible and user-friendly browsing experience.
- Use responsive CSS so the website can be viewed on desktop, tablet and mobile devices.

## 3. Target Audience
- Book lovers
- Students
- Coffee lovers
- Families
- People looking for a quiet place to read or relax

## 4. Main Features
- Home page with a welcome message, café image and call-to-action.
- About Us page with the café's story, mission, vision and team.
- Books & Café page showing books, drinks and treats.
- Featured books table with prices and availability.
- Enquiry page with a customer enquiry form.
- Contact page with contact details, locations and opening hours.
- Navigation menu linking all pages.
- Book and café images with alternative text.
- Responsive external CSS stylesheet.
- Footer with copyright information.
- Hover and focus states for links and form controls.

## 5. Design Aesthetic
- Warm and cosy appearance.
- Cream, brown and soft beige colour palette.
- Readable typography with clear heading hierarchy.
- Rounded cards and subtle shadows.
- Book and coffee-themed imagery.
- Comfortable spacing and uncluttered layouts.
- Responsive design for different screen sizes.

## 6. Technical Requirements
- HTML5 for website structure and content.
- CSS3 for presentation, layout, colours, typography and responsive design.
- Visual Studio Code for development.
- GitHub for version control and project submission.
- Modern web browser such as Chrome, Edge or Firefox for testing.
- External stylesheet stored in `css_assets/style.css`.
- Relative links used for local pages and images.
- Responsive viewport meta tag included on every page.
- Form labels connected to their input fields.
- Alternative text supplied for meaningful images.

# Proposal 2: Cozy Book Café - Modern Reading Lounge

## 1. Website Concept
This proposal presents The Cozy Book Café as a modern reading lounge aimed at students, young adults and book lovers. The website will have a modern, clean and visually engaging design while still keeping the café's welcoming atmosphere.

## 2. Goals and Objectives
- Attract customers through an appealing website.
- Showcase books and café products.
- Encourage customers to visit the café.
- Make it easy for customers to send enquiries.
- Provide clear location, opening-hour and contact information.
- Create an easy-to-use browsing experience.
- Make the site responsive and visually consistent across devices.

## 3. Target Audience
- Students
- Young adults
- Book lovers
- Coffee lovers
- People interested in reading and socialising

## 4. Main Features
- Home page with a hero section and call-to-action.
- Featured books section.
- Café drinks and treats sections.
- About Us information.
- Enquiry form.
- Contact and locations page.
- Navigation menu on every page.
- Book categories such as Fiction, Romance, Fantasy, Self-development and Classics.
- Images of the café, books and products.
- Responsive CSS layout.
- Styled tables, forms, links and buttons.
- Consistent footer across all pages.

## 5. Design Aesthetic
- Modern and minimalist appearance.
- Soft neutral colours with a warm accent colour.
- Modern headings and readable body text.
- Card-style content sections.
- Clear navigation.
- Responsive grid layouts.
- Strong visual hierarchy and whitespace.

## 6. Technical Requirements
- HTML5 semantic structure.
- CSS3 external stylesheet.
- Responsive layouts using CSS Grid, Flexbox and media queries.
- Visual Studio Code.
- GitHub version control.
- Chrome, Edge or Firefox for testing.
- Local image assets stored in `_images`.
- CSS stored in `css_assets/style.css`.
- Accessible labels, alternative text and keyboard-friendly focus states.
