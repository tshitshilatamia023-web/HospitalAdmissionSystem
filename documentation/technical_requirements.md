# Technical Requirements - The Cozy Book Café

## Hardware Requirements
- Desktop or laptop computer.
- Keyboard and mouse/touchpad.
- Internet connection for GitHub access and online resources.

## Software Requirements
- Visual Studio Code or another HTML/CSS editor.
- Modern web browser such as Google Chrome, Microsoft Edge or Mozilla Firefox.
- Git and GitHub for version control and submission.

## Web Technologies
- HTML5 for page structure and content.
- CSS3 for styling, layout, typography and responsive design.
- CSS Flexbox and Grid for page layouts.
- CSS media queries for responsive behaviour.
- JavaScript for client-side enquiry form validation and user feedback.
- Google Maps embedded maps for the two café locations.

## Quality and Accessibility Requirements
- Use semantic HTML5 elements.
- Include a viewport meta tag on every page.
- Use descriptive `alt` text for meaningful images.
- Use labels for form controls.
- Provide visible hover and focus states.
- Use readable font sizes and adequate spacing.
- Keep colour contrast readable.
- Use relative paths for local files.
- Test all navigation links and form controls before submission.

## Part 2 CSS Requirements
The external stylesheet should provide:
- A consistent colour palette.
- Typography and heading styles.
- Header and footer styling.
- Navigation styling and interaction states.
- Section/card styling.
- Table styling.
- Form styling.
- Responsive layouts.
- Mobile navigation and content adjustments.

## Responsive Image Requirements
- Use `srcset` and `sizes` on meaningful website images.
- Provide image variants at different widths so browsers can select an appropriate file for the viewport.
- Keep images fluid with `max-width`, intrinsic sizing, and `height: auto`.

## JavaScript
- Use `js_assets/script.js` for client-side enquiry form validation and user feedback.
