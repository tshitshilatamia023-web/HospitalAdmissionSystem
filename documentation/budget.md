# The Cozy Book Café - Project Budget

## Budget Overview

The Cozy Book Café website is being developed as an academic web development project. The website can be developed using free tools and resources, while optional costs are included below to show what would be required if the website were published as a professional business website.

## Budget Assumptions

- The project is developed by the student, so no external developer fee is included.
- Visual Studio Code, GitHub, web browsers, HTML5, CSS3 and JavaScript do not require a project purchase for this academic website.
- Free image resources are used where their licences allow the intended use.
- The Google Maps embedded maps are included as part of the website demonstration; any future production use should be checked against Google's current Maps terms and pricing.
- Domain and hosting costs are estimates for planning purposes and may vary depending on the provider and package selected.
- Maintenance costs are an estimated allowance for future updates and are not required for the current academic submission.

## Budget Justification

The largest potential costs would be publishing the website online through a domain and web-hosting service. Development itself has no required software cost because the website uses standard web technologies and free development tools. Including both the current academic costs and optional professional costs provides a realistic budget for the project and shows how the website could be maintained after development.
