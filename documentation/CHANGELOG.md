# The Cozy Book Café - Changelog

## Version 1.2 - Part 2 Rubric Improvements

### Part 1 Feedback Corrections
- Expanded the project documentation to clearly explain the current website analysis and the improvements made from Part 1 feedback.
- Updated the project budget with development, domain, hosting, maintenance and other estimated costs.
- Updated the technical requirements to include JavaScript and Google Maps.

### CSS Styling
- Strengthened the external stylesheet used across all five HTML pages.
- Added a complete CSS reset for consistent browser rendering.
- Added typography, spacing, colours, borders, box shadows and layout styling.
- Added CSS Grid and Flexbox layouts for desktop and responsive sections.
- Added `:hover`, `:focus`, and `:active` pseudo-classes for links and form controls.
- Added an explicit tablet breakpoint at 1024px and a mobile breakpoint at 700px.
- Updated mobile layouts so multi-column sections stack into a single column.
- Added responsive styling for the Contact page maps.

### Responsive Images
- Added responsive JPG image variants in the `_images` folder.
- Added `srcset` and `sizes` attributes to website images so the browser can select an appropriate image size for different screens.

### JavaScript
- Added `js_assets/script.js`.
- Added client-side validation and user feedback for the enquiry form.

### Testing Evidence

- Tested the homepage at desktop, tablet and mobile viewport sizes using browser developer tools.

### Contact Page
- Added a Rosebank Google Maps embed.

- Added responsive map cards so the two maps display in columns on larger screens and stack on mobile.
